# Specification-to-TLF in R: demo

Demo for the PHUSE EU Connect 2026 talk "Specification-to-TLF in R" (session ET10). It follows one synthetic demographics table from a static shell to a table with computed numbers. All content is synthetic.

- `index.html`: the demo. Choose **Video** to play it with its timing, or **Slides** to click through. Choosing a mode goes full screen and hides the controls; Space brings them back.
- `ET10_demo_slides.pdf`: the demo as a 20-page slide deck.
- `ET10_demo.mp4`: the demo as a video (9:50).

The second half (ARS export, generated code, results) is illustrative: the numbers are computed for real on public synthetic data, but the code is hand-written and the integration is not built.
